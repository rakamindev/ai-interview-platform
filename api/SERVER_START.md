# Cara Menjalankan Server Backend (API)

1. Buka Terminal / Command Prompt baru.
2. Masuk ke dalam folder `api`:
   ```bash
   cd api
   ```
3. Jalankan perintah ini untuk menyalakan server Rails:
   ```bash
   rails server
   ```
   Atau jika menggunakan bundle:
   ```bash
   bundle exec rails server
   ```

Server akan berjalan secara otomatis di port **3001**.
Untuk menghentikan server, tekan `Ctrl + C` di terminal tersebut.
