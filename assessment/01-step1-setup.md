## 2. What I changed to make it run (local-only, committed separately)

- **`api/Gemfile` + `api/Gemfile.lock`** — bumped `ruby '3.3.2'` → `'3.3.10'` so Bundler resolves on the local Ruby 3.3.10 toolchain (`Bundler::RubyVersionMismatch` otherwise).
- **`web/package-lock.json`** — generated by `npm install` (was not present in the repo).

## 3. Issues hit during setup (documented for the report)

1. **Ruby version mismatch** — Gemfile pinned 3.3.2, local Ruby 3.3.10 → `Bundler::RubyVersionMismatch`. Fixed by bumping Gemfile.
2. **Redis `NOAUTH`** — the shared local Redis container has a `requirepass` set, but `config/application.yml` had a password-less `REDIS_URL`. Fixed locally by adding auth to `REDIS_URL` (local-only, file is gitignored).
3. **macOS fork crash** — Puma workers crashed with `+[NSCharacterSet initialize] ... in fork() child process`. Fixed by launching with `OBJC_DISABLE_INITIALIZE_FORK_SAFETY=YES`.
4. **PostgreSQL absent** — installed via Docker: `docker run -d --name postgres -e POSTGRES_PASSWORD=<local-dev-pass> -e POSTGRES_USER=postgres -p 5432:5432 postgres:16-alpine`.
5. **No seeded users** — `db:seed` creates the test org + 22-skill B7 taxonomy only; JWTs are minted manually via `JsonWebToken.encode({ user_id: 1, role: 'admin', scheme: 'test-corp' })` and used as `VITE_DEV_TOKEN` for the web app.
