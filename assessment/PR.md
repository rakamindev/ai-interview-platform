Recruiters could see a skill gap without its required level because the API emitted `expected_level` while the frontend read `required_level`. The review flow also lost reports on refresh failure, omitted rating provenance, and allowed portfolio/override lookups outside the authenticated tenant.

This change adds a portfolio-to-vacancy review workflow: deterministic comparisons with human-review provenance, explicit unassessed requirements, source fingerprints, persisted processing/retry states, tenant ownership checks, and consistent PDF/JSON exports. The UI supports evidence inspection, follow-up filtering, stale/failed snapshots, native disclosure activation, and narrow screens. Portfolio response validation prevents invented L1 ratings and preserves human overrides during regeneration.

The comparison deliberately replaces unsupported AI culture/hiring narratives with an evidence-based summary. Existing live interview behavior is outside this change.
