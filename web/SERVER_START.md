# Cara Menjalankan Server Frontend (Web)

1. Buka Terminal / Command Prompt baru.
2. Masuk ke dalam folder `web`:
   ```bash
   cd web
   ```
3. Jalankan perintah ini untuk menyalakan Vite development server:
   ```bash
   npm run dev
   ```

Server akan berjalan secara otomatis di port **5173**.
Anda bisa mengakses aplikasinya melalui browser di alamat: `http://localhost:5173`

Untuk menghentikan server, tekan `Ctrl + C` di terminal tersebut, lalu tekan `Y` dan Enter jika diminta.
